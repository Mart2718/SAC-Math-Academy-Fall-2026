# SAC Math Academy revised version

This folder is a separate revised copy of the supplied GitHub download.

## Changes
- Course navigation on all statistics pages.
- Dedicated Practice & Review and AI Study Partner pages.
- Course purpose and student-centered introduction.
- Visible outcome lists with module labels.
- Outcome jump links and sample problems within Step 4, before self-checks.

- Development placeholders hidden; finished resource records preserved.
- Improved small-screen wrapping, keyboard skip link, route focus, and reduced-motion styling.

## Open the website
Create a separate Netlify site and drag this entire folder into its manual deployment area. The folder must contain index.html at its top level, alongside data and images. Alternatively, upload these files to a new GitHub repository and connect that repository to a separate Netlify site.

No new GitHub repository or public deployment has been created by this download.

## Validation and limits
JavaScript syntax and generated markup for all 23 outcome pages, course home, AI guide, review, midterm, apps, search lookup, and practice ordering passed local checks. Content tables were checked against the supplied archive. Mathematical questions and answer data were preserved.

A browser preview of the local build was blocked by the browser environment, so rendered desktop/mobile layout and end-to-end interactions still need checking in the separate Netlify preview. External resource permissions were not revalidated.

The supplied images folder contains no graph assets. MISSING-ASSETS.txt lists referenced graph files to recover from the original Claude project. The graph questions and their references remain intact.
